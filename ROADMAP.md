# ROADMAP: усиление движка и агентов (составлен 19.07.2026)

Две проблемы: (А) движку нужны готовые «мышцы» — звук, шрифты, анимации, переходы;
(Б) агенты работают, но сценарист пишет шаблонно, а режиссёр не создаёт новые
визуалы без прямого приказа. (Б) — главная: без неё библиотека не растёт.

---

## Трек Б. Агенты 2.0 — механика принуждения к творчеству

### Диагноз, почему режиссёр не творит
1. Промпт делает создание нового визуала «аварийным люком» и даёт разрешение
   слиться («не уверен в силах — оставь лучший доступный»). Модель всегда
   выбирает безопасный путь, если он разрешён.
2. Проверка нового визуала дорогая: нужен полный эпизод с озвучкой. Дорогой
   тест → страх экспериментов.
3. Движок самомодифицируется без версионирования — сломать страшно.
4. Рост библиотеки нигде не измеряется — нет давления.

### Исправление (не «уговорить», а перестроить стимулы)

**Б1. Gap-скан — обязательный шаг режиссёра.**
Перед сборкой JSON: таблица «глагол/сущность реплики → лучший визуал → оценка
соответствия 1–5». Любая оценка ≤3 попадает в очередь кузницы. Правило: либо
создай визуал, либо письменно обоснуй, почему существующий тянет на 4+.
«Не хватило языка» перестаёт быть строчкой отчёта и становится задачей.

**Б2. Кузница визуалов (visual forge) — дешёвый цикл проверки.**
Новая Preview-композиция в движке: рендер ОДНОЙ сцены с синтетическими
таймингами слов (без TTS!) — still за секунды:
`npx remotion still Preview out.png --props='{"scene": {...}, "fakeWords": true}'`
Рецепт кузницы в SKILL.md: спека визуала → компонент по образцу → регистрация
(types + schema + Root + catalog.md) → tsc → Preview-скриншот → Read → правка.
Дёшево и безопасно → смелость становится рациональной.

**Б3. Git-страховка.** `git init`, коммит на каждый новый визуал и каждый эпизод.
Pre-flight перед рендером: tsc + validate.py + Preview-скриншот. Сломал — откатил.

**Б4. Каталог = память системы.** Новый визуал обязан появиться в catalog.md
(строка «когда использовать») в том же коммите. Отчёт режиссёра содержит поле
«новых визуалов: N». Продюсер (/produce) заворачивает работу, если gap-скан
показал дыры (оценки ≤3), а N = 0.

**Б5. Сценарист 2.0 — бриф вместо шаблона.**
- Убрать жёсткие роли блоков (hook/explain/depth/outro) как предписание.
  Оставить только рамки движка: 4–7 блоков-сцен, 120–160 слов, разметка
  {SHOW|скажи}, финальный блок с мостиком.
- Вместо шаблона — бриф формата: шортсы/рилсы/тикток, 55–70 сек, удержание,
  паттерн-интерапт каждые ~8 сек, одна тема — глубоко.
- **Меню нарративных приёмов** (выбирает под тему, повторять приём последних
  5 роликов запрещено — обязан прочитать существующие эпизоды): миф-бастер;
  сценка-диалог двух устройств; детектив (симптом → расследование → разгадка);
  «а что если убрать X»; versus-сравнение; история реального инцидента;
  цифра-шок; обратный отсчёт; «объясни как пятилетнему, потом как инженеру».
- **Ресёрч обязателен**: добавить сценаристу WebSearch/WebFetch; минимум
  3 конкретных факта из поиска, один — «вау» с проверяемым источником.
  Это лечит одинаковость сильнее любых стилевых указаний: разные факты →
  разные ролики.

**Б6. Третий агент — критик (замыкает луп).**
После рендера stills каждой сцены → мультимодальная проверка (Read кадров
агентом; позже — Gemini vision как второе мнение): читаемость, перекрытия,
пустые/скучные сцены (нет импактов >8 сек), совпадениеударов со словами.
Вердикт: принять / список правок режиссёру (SendMessage, макс 2 итерации).
Паттерн подтверждён исследованиями (Code2Video: Planner→Coder→Critic).

## Трек А. Усиление движка (проверено в сети 19.07.2026)

**А1. Официальные пакеты Remotion** ([docs](https://www.remotion.dev/docs/)):
- `@remotion/layout-utils` — measureText/fitText/fillTextBox: автоподгонка
  текста → класс багов «наехало/вылезло» исчезает системно.
- `@remotion/transitions` — TransitionSeries: fade/slide/wipe/flip/clockWipe/iris
  между сценами (сейчас жёсткая склейка).
- `@remotion/google-fonts` — типографика: кириллические Montserrat/Unbounded/
  Inter вместо Liberation Sans. Самый дешёвый визуальный апгрейд.
- `@remotion/paths` — кривые траектории пакетов (дуги, evolvePath для
  прорисовки линий), warpPath для «живых» стрелок.
- `@remotion/noise` — органический дрейф вместо синусов.
- `@remotion/shapes` — Star/Pie/Polygon для новых визуалов.
- `npx remotion skills add` — официальные скиллы Remotion в помощь режиссёру.

**А2. Готовые анимации:**
- `@remotion/lottie` + [LottieFiles free](https://lottiefiles.com/page/license)
  (бесплатные — можно коммерчески, без атрибуции) + [Lordicon](https://lordicon.com)
  (18 500+ анимированных иконок, есть бесплатный набор). Кузница получает
  «готовые запчасти»: анимированный замок, щит, лупа, огонь.
- `@remotion/rive` — опция на потом (стейт-машины).

**А3. Звук — самый недооценённый прирост «сочности»:**
- SFX на импакты ИЗ ДВИЖКА (агенту думать не надо): вуш при полёте пакета,
  поп при прилёте/слэме, клик в browser-click, «дзынь» на state-бейдже.
  Источники CC0 (без атрибуции): [Mixkit](https://mixkit.co/free-sound-effects/whoosh/),
  [Pixabay](https://pixabay.com/sound-effects/search/cc0/), VideoEditingSFX.
  Отобрать ~15 звуков один раз, положить в repo.
- Фоновая музыка CC0 (Pixabay Music) + ducking под голос (volume-кривая в
  <Audio> по таймингам реплик — тайминги уже есть).
- Схема: sfx автоматически привязывается к типам событий; переопределение
  в JSON — опционально.

**А4. Код-сцены:** shiki-подсветка в CodePanel (реальные цвета синтаксиса).

**А5. Не берём (проверено):** remotion-superpowers (завязан на платные KIE/
TwelveLabs), Rendervid (маркетинговые шаблоны), OpenMontage целиком (generic,
en-центричный) — но их идеи (review-loop, футажи Pexels/Archive.org) уже в плане.

## Порядок внедрения

**Фаза 1 — фундамент роста (сначала!):** git init → Preview-композиция →
fitText в текстовые примитивы → google-fonts → SFX-набор в движок.
Без Preview и git кузница (Б2) не заработает.

**Фаза 2 — агенты 2.0:** переписать scriptwriter.md (бриф+приёмы+ресёрч),
animation-director.md (gap-скан+кузница+отчёт N визуалов), добавить critic.md,
обновить /produce (луп с критиком, отказ при N=0 с дырами).

**Фаза 3 — богатство:** transitions между сценами, Lottie/Lordicon-запчасти,
кривые траектории (paths), shiki, фоновая музыка с ducking.

**Фаза 4 — поток (прежний план):** GitHub Actions рендер, SQLite-каталог тем,
Telegram-бот апрува, публикация.

Мерило успеха: через 10 роликов в каталоге ≥8 визуалов (сейчас 4+5 типов сцен),
и ни один не добавлен по прямому приказу пользователя.
