# Каталог сцен (v1)

Эпизод = 4–7 сцен, начинается с `story` (или простого `hook`) и заканчивается `outro`.
Реплика сцены — 1–3 предложения, ~7–12 секунд речи.

## hook — открывающий кадр
Крупный заголовок, слова влетают по одному; субтитров нет (заголовок и есть текст).
Хук должен создавать интригу или обещание за первые 2 секунды.

| Поле | Что писать |
|---|---|
| `title` | ≤6 слов, цепляющий («3 пакета, без которых нет интернета») |
| `subtitle` | необязателен; тема + время («TCP handshake за 50 секунд») |

## story — сториборд: каждая фраза обыграна своим битом
Лучший опенер. Сцена = последовательность битов; бит стартует на слове-якоре
`onWord`, между битами камера прыгает (зум/сдвиг). Каждое слово диктора получает
свою картинку — максимум движения.

Визуалы битов (v1):
| visual | Что происходит | params |
|---|---|---|
| `browser-click` | окно браузера, рука-курсор влетает и кликает по ссылке, камера доезжает к клику | `url` |
| `devices-meet` | телефон слева и сервер справа съезжаются к центру | — |
| `handshake` | те же устройства + вспышка-рукопожатие, искры, кольца (ставь после devices-meet — переход бесшовный) | — |
| `title-slam` | заголовок влетает с ударом и кольцом | `text`, `sub` |
| `password-leak` | терминал печатает пароль точками; по «энтеру» буквы голым текстом улетают по проводу вправо, сбоку загорается наблюдающий глаз | `password` (демо-строка, по умолчанию `hunter2`) |
| `hash-table` | ключ проходит через хеш-функцию и приземляется в подсвеченную ячейку массива | `key`, `hash`, `index`, `value` |
| `collision-compare` | два ключа сталкиваются в одном индексе; слева собираются в цепочку, справа занимают следующую свободную ячейку | `keyA`, `keyB`, `bucket` |
| `heap-graph` | корень ведёт по ссылкам к живым объектам, а отдельный цикл подсвечивается как недостижимый | `mode`: `roots` или `unreachable` |
| `gc-sweep` | фазы mark и sweep: достижимые объекты получают метки, непомеченные исчезают; режим `generations` показывает молодую и старую кучу | `mode`: `mark-sweep` или `generations` |
| `medal-mint` | круглая медаль: девиз гравируется по ободу дугой символ за символом, затем чеканка (удар, кольцо) выбивает в центре крупные `1` (циан) и `0` (фиолет) | `motto` (латинский девиз по ободу), `caption` (подпись под медалью) |
| `ancient-code` | древний артефакт превращается в биты: режим `hexagram` — вертикальный столбец из 6 линий И-цзин (сплошная/прерывистая), режим `syllable` — горизонтальный ряд слогов стиха (долгий/краткий); рядом с каждым штрихом всплывает 1/0 своего цвета, внизу — итоговое число | `mode`: `hexagram` или `syllable`, `label` (подпись артефакта) |

Когда использовать `password-leak`: любой сюжет про пароль/секрет, уходящий по сети
в открытом виде — перехват, незашифрованный логин, демонстрация уязвимости.

Когда использовать `hash-table`: буквальное объяснение хеш-функции, индекса массива и быстрого поиска по ключу.

Когда использовать `collision-compare`: сравнение chaining и open addressing на одной и той же коллизии; не заменяет общий `diagram`, если нужны произвольные узлы и пакеты.

Когда использовать `heap-graph`: буквальное объяснение достижимости от корней, цепочек ссылок и отсоединённых циклов; `mode: roots` — для старта обхода, `mode: unreachable` — для мусора.

Когда использовать `gc-sweep`: буквальное объяснение фаз mark-and-sweep или поколений кучи; `mode: generations` — когда речь о частой уборке молодой части и редком сканировании старой.

Когда использовать `medal-mint`: сюжет буквально про медаль/монету/печать с девизом, которая
чеканит или проявляет два символа (в бинарной истории — 1 и 0); не для абстрактных «двух
состояний» без физического предмета-медали.

Когда использовать `ancient-code`: показать, что задолго до текущего героя кто-то уже
записывал двоичную идею в другой форме — гексаграммы, слоги стиха, любой историко-культурный
код, который переводится в 0/1; `mode: hexagram` — линии/триграммы, `mode: syllable` — метрика
стиха или другая последовательность длинный/короткий.

Правила: 2–6 битов; каждому биту (кроме первого) — `onWord` на слово, с которого
начинается его фраза; порядок битов = порядок фраз реплики. Новый визуал нужен —
добавь компонент в StoryScene.tsx + enum в схему + строку в эту таблицу.

## diagram — сущности и данные между ними
Главная сцена языка. Узлы располагаются вертикально (1–3), между ними пунктирная
линия; пакеты-пилюли летят от узла к узлу; опционально бейдж итога `state`.

| Поле | Что писать |
|---|---|
| `nodes` | 1–3 узла: id, label ≤20 симв, icon (lucide), tone |
| `packets` | ≤4 за сцену; label ≤14 симв; ставь `onWord` на слово, где пакет упоминается |
| `state` | итог сцены («Соединение установлено»), tone success/danger, `onWord` на ключевое слово |

Когда: любой обмен/поток данных, атаки (злоумышленник = узел с icon skull, tone danger),
клиент-сервер, слои, «кто кому что шлёт».

**Поле `channel`** (необязательное, на всю сцену): `open` — дырявый красный
пунктир с иконкой открытого замка посередине (канал читается кем угодно, для
сцен про перехват/уязвимость); `encrypted` — светящийся зелёный туннель с
иконкой закрытого замка (для сцен про шифрование/защищённый канал). Без поля —
старый нейтральный серый пунктир (обратная совместимость).

**Поле `secret`** у узла (`nodes[].secret`, ≤16 симв): подпись-бейдж с замком
рядом с узлом, который не летит пакетом — использовать, когда узел держит
что-то при себе (тайное число Диффи-Хеллмана, приватный ключ) и это принципиально
не путешествует по сети.

## terminal — команда и её вывод
Окно терминала, команда печатается посимвольно, вывод появляется построчно.

| Поле | Что писать |
|---|---|
| `commands` | 1–3 команды; cmd ≤46 симв; output ≤6 строк по ≤46 симв (обрезай реальный вывод до сути) |

Когда: «проверь сам», демонстрация утилит (tcpdump, dig, curl, nmap...). Реплика должна
ссылаться на то, что видно в выводе.

## code — фрагмент кода
Панель кода с построчным появлением и подсветкой ключевых строк.

| Поле | Что писать |
|---|---|
| `code` | ≤14 строк по ≤46 симв; только суть, без боилерплейта |
| `highlight` | номера строк (с 1), о которых идёт речь в реплике |

Когда: конфиги, заголовки протоколов, примеры уязвимого кода. Не используй для команд —
для них terminal.

## outro — финал
Заголовок, 2–4 пункта-вывода, пульсирующая CTA-кнопка.

| Поле | Что писать |
|---|---|
| `bullets` | выжимка ролика, ≤34 симв каждый |
| `cta` | подписка + мостик к следующему ролику («Подпишись: дальше — SYN-flood») |

Реплика outro обязана: повторить главное + анонсировать следующий ролик.
