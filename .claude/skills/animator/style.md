# Правила стиля (нарушать нельзя)

## Драматургия ролика (~55 сек)
1. **Хук** (0–5 с): интрига или обещание. Без «привет, сегодня мы поговорим о».
2. **Объяснение** (5–35 с): 2–3 сцены, одна мысль на сцену.
3. **Углубление** (35–45 с): один «вау-факт» или «проверь сам» — то, чего нет в первой
   строке Википедии.
4. **Финал** (45–55 с): выжимка + мостик к следующему ролику.

## Текст реплик
- Весь эпизод: 120–150 произносимых слов (≈55 сек при +8% темпа Дмитрия).
- Устная форма: числа словами, без markdown, короткие предложения. Разговорно,
  на «ты», без канцелярита и без клише («в современном мире», «давайте разберёмся»).
- Каждый термин — через разметку `{SHOW|скажи}` по словарю транслитерации
  (`~/.claude/commands/tts.md`): {TCP|ти си пи}, {SSH|эс эс эйч}, {DNS|ди эн эс}.
  Ударения в спорных словах — U+0301: «ша́га».
- Точность фактов важнее краткости: не упрощай до неправды. «Углубление» должно быть
  технически корректным и проверяемым.

## Композиция кадра (1080×1920)
- Safe-зоны: сверху 150px и снизу 270px ничего смыслового (там UI платформ и субтитры).
- ≤4 смысловых элемента в кадре одновременно. Сомневаешься — дели на две сцены.
- Подписи узлов ≤20 символов, лейблы пакетов ≤14, строки кода/терминала ≤46.
- Цвета только семантически: accent — главное, accent2 — вторая сторона,
  success — успех/итог, danger — атака/ошибка, warning — предупреждение.

## Моушн (даёт движок автоматически — знай, что происходит)
Кадр никогда не статичен: фон дрейфует (сетка, частицы, дышащее пятно света),
каждая сцена входит пружиной и медленно наезжает камерой (Ken Burns ~5%),
узлы диаграмм парят, пакеты летят со шлейфом и покачиванием. Импакты — прилёт
пакета, появление бейджа — дают тряску камеры, пульс узла и расходящиеся кольца.
Караоке-слова «выстреливают» пружиной в момент произнесения.

Следствия для сценариста:
- Не бойся «медленных» сцен — движение есть всегда; но реплика сцены >12 сек — всё
  равно плохо, дели.
- Импакт = смысловой удар. Ставь onWord так, чтобы прилёт пакета совпадал с ударным
  словом реплики — тряска подчеркнёт его.
- Не перегружай: 3–4 импакта на сцену максимум, иначе тряска превращается в шум.

## Синхронизация
- Каждому пакету и бейджу state ставь `onWord` — элемент появляется в момент
  произнесения слова. Слово должно реально быть в реплике этой сцены (в форме SHOW).
- Порядок пакетов в массиве = порядок упоминания в реплике.
