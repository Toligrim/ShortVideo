# Motion gap-скан технического примера

`motion-engine.json` использует реплики и alignment существующего эпизода
`auto-20260910-052001`. Цель — показать контракт ядра на пяти фазах одного
переиспользуемого визуала. Это не новый производственный выпуск.

| Идея | Бит/фаза | До → после | Нужный ход / покрытие | Оценка | Якорь / объект |
|---|---|---|---|---|---|
| Одинаковый ник, разные исходы | Сцена 0, request | Два равных запроса → A принят, B отброшен | cascade + pulse/recoil; compare камеры | 5 | resolve=принимает; request-a / request-b |
| Проверка не резервирует значение | Сцена 1, check | Два запроса далеко от индекса → оба читают одну пустую строку | useMotion act ведёт два SVG-пробника; follow | 5 | act=проверить; probe-0 / probe-1 |
| Одно значение у уникального индекса | Сцена 2, insert | Два претендента → одна записанная строка | transfer + исчезновение запросов; focus | 5 | act=UNIQUE INDEX; request-a / request-b / index |
| Ожидание и отказ конкуренту | Сцена 3, wait → conflict | B припаркован у замка → A зафиксирован, B отскакивает | transfer / recoil + pulse; match фаз, settle камеры | 5 | act=ждёт, resolve=завершения; затем act=конфликт, resolve=копию |
| Итог ограничения | Сцена 4, outro | Распределённая механика → краткий итог | dissolve стыка + settle | 4 | camera=Гарантия |

Входящие стыки: сцена 1 — turn/push (вход внутрь системы), сцена 2 —
contrast/wipe (от проверки к ограничению), сцена 3 — continuation/match,
финал — finale/dissolve. Каждому соответствует изменение способа чтения
картинки, а не смена доминирующей цветной заливки.

Все пять идей покрыты стартовым словарём ядра ≥4. Дополнительных bespoke
примитивов для этого эпизода нет. Единственный переработанный визуал —
`unique-insert-race`; в нём ≤4 смысловые группы. Camera не засчитывается
вместо движений объектов. Для request результат подтверждают кадры
331/344/356; для check — 625/638/650; insert — 941/954/966; wait —
1438/1448/1456; conflict — 1535/1547/1559. Это вывод `motionAudit` из alignment,
не ручные длительности сценария.

`motion.actors.request-b` в conflict показывает выбор recoil из JSON; те же
параметры подойдут для отказа пакету на шлюзе или возврата задачи из очереди.
Остальные действия поставляет контракт визуала. Stable id SVG-пробника
`probe-0` служит диагностике, но не является MotionGroup и не принимает
JSON override; smoke обнаружит попытку назначить ему такой ход.
