- Всего действий разобрано: **9**
- Из них с оценкой ≤3 (попадают в очередь кузницы): **8** (№2–9)
- С оценкой ≥4 (можно собирать из готового): **1** (№1 — замочек/браузер)

Правило: оценка ≤3 → собирать сцену на этом визуале запрещено без письменного обоснования. Обоснования «не был уверен в силах» не принимается, есть кузница с дешёвой проверкой.

### Решение режиссёра

Большинство ключевых действий (2–9) получают ≤3 — готовых визуалов буквально нет. Требование кузницы обязательно. Создан новый визуал:

**`tls-handshake` в `video/src/scenes/TlsHandshakeVisual.tsx`** с тремя фазами:

- `certificate` — браузер ↔ сервер, сертификат летит посередине: `example.com` + `K = 04af…7e` + бейдж «подпись ЦС», снизу бейдж «домен ↔ открытый ключ». Буквально ведёт от замочка к проверке «домен связан с ключом».
- `derive` — клиент держит `a — секрет / не летит`, сервер `b — секрет / не летит`, обмениваются только `A=gᵃ` / `B=gᵇ` (стрелки), оба выводят `S=gᵃᵇ` (два одинаковых зелёных блока), перечеркнутая диагональ «S в сети нет». Буквально показывает «секрет нигде не летит — выводят сами, подслушать нечего».
- `channel` — светящийся шифро-канал с замком между браузером и сервером, внутри запечатанное письмо «ложь?», глаз перехватчика перечёркнут `eye-off`, снизу бейджи «канал защищён / сайт может лгать» и итог «канал надёжен — отправитель не проверен». Буквально раскрывает метафору письма и финальный тезис «канал защищён, сайт не обязательно честен».
