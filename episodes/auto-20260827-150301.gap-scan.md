# Gap-scan: auto-20260827-150301

Тема: «Почему сайт не может показать твой забытый пароль, а только сбросить».
Драфт: `episodes/drafts/auto-20260827-150301.draft.json` (7 блоков → 5 сцен).

## Раскадровка (сущности / действия / ударные слова)
1. Забыл пароль → ищу кнопку «показать» → нет, только «сбросить» (хук).
2. Пароль «лежит в файле» → хакер крадёт базу → читает все пароли сразу.
3. У сайта пароля нет → хранят отпечаток (хэш) + соль.
4. Односторонний хэш как мясорубка → сервер пересчитывает и сравнивает, не расшифровывает.
5. Соль → одинаковые пароли дают разные строки → радужные таблицы биты.
6. NIST требует соль ≥32 бит, OWASP советует Argon2id.
7. Выжимка + мостик к «почему советы "сложный пароль" устарели».
