## Визуал в кузнице

### `recommendation-loop` — поведение зрителя становится новым порядком

- Документация: `.claude/skills/animator/catalog.md`, строка `recommendation-loop`; реализация: `video/src/scenes/RecommendationLoopVisual.tsx`; регистрация: `video/src/scenes/StoryScene.tsx`, `video/src/lib/types.ts`, `schema/scenes.schema.json`.
- `phase: feed`, `view: watch` — карточка ролика доходит до 100%, рядом явно остаются ненажатые лайк и подписка; `view: similar` — похожие карточки входят в следующую ленту с собственными score.
- `phase: explicit` — явный лайк показан отдельной крупной кнопкой-сердцем.
- `phase: signals` — четыре разные поведенческие дорожки: `ДОСМОТР`, `ПАУЗА`, `СВАЙП`, `ВОЗВРАТ`; они не сливаются в одну стрелку и сходятся в панели «ОЦЕНЩИК ПОВЕДЕНИЯ». `focus` подсвечивает действие, `all` оставляет все дорожки активными.
- `phase: analogy`, `view: seller` / `pause` — продавец фиксирует полку, покупатель задерживается, а плашка «ПОКУПКИ НЕТ» показывает, почему отсутствие покупки не стирает наблюдение.
- `phase: score`, `view: ranker` / `recalculate` — реальные карточки кандидатов с полосами `SCORE`, четыре входа оценщика и изменение значения похожего кандидата `0.31 → 0.78`.
- `phase: reorder` — список роликов анимированно меняет позиции `№3 → №1`; `view: chance` показывает рост следующей вероятности `18% → 64%`.
- Параметры: `phase` (`feed` / `explicit` / `signals` / `analogy` / `score` / `reorder`), `view` (`watch` / `similar` / `seller` / `pause` / `ranker` / `recalculate` / `chance`), `focus` (`watch` / `pause` / `swipe` / `return` / `all`).
- Импакт: `feed` 0.62, `explicit` 0.58, `signals` 0.68, `analogy` 0.62, `score` 0.66, `reorder` 0.72 локальной длительности бита; каждый бит начинается на `onWord`, после него появляется соответствующее изменение.
- Композиция: header около y=220, панели y=385–1090, итоговый бейдж y=1210; всё смысловое выше y=1500 и помещается в safe-зоны 150px сверху / 420px снизу. Визуал держит не более четырёх смысловых групп на фазу.
