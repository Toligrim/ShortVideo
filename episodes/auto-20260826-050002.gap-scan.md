## Выделение оценок ≤3 (очередь кузницы)

- **№1 — 1**, **№2 — 1**: буквальная смена сети Wi-Fi→4G с тем же видео/ID. Лучший кандидат `devices-meet`/`handshake` — про установку соединения в одной сети, не про миграцию. Требуют буквального визуала с двумя трассами и CID.
- **№7 — 2**: отправка того же CID с нового адреса. `diagram` с пакетом CID с нового IP даёт 2, потому что не показывает одновременно старый перечеркнутый Wi-Fi и новый подсвеченный 4G с бейджем SAME — ключевой визуальный контраст теряется.
- **№8 — 3**: PATH_CHALLENGE/PATH_RESPONSE. `diagram` дотягивает до 3 (две пилюли), но без привязки к миграционным трассам зритель не поймет, что это именно валидация нового пути миграции, а не обычный обмен.
- **№9 — 3**: итог валидации «это ты». `diagram` state даёт 3 — бейдж без контекста трасс/CID не убеждает, что соединение именно продолжилось после смены сети.

Итого: **5 действий из 11 с оценкой ≤3** (№1,2,7,8,9). Все попадают в очередь кузницы по правилу «≤3 → в кузницу, собирать сцену на таком визуале запрещено без письменного обоснования».

## Решение кузницы

Честная очередь — 5 позиций, но тема требует **одного буквального визуала**, покрывающего именно смену сети:

- **Создан ровно один новый визуал `quic-migration`** (`video/src/scenes/StoryScene.tsx` → `QuicMigrationVisual`, тип `QuicMigrationPhase`):
  - `phase: wifi` — только Wi-Fi активен, CID 7A·3F SAME поверх IP, подпись «CID живёт поверх IP», телефон 192.168.1.5
  - `phase: migrate` — Wi-Fi перечеркнут красным (обрыв), 4G подсвечен, IP телефона меняется на 37.214.5.9, бейдж «тот же CID — новый путь», PulseRing на 4G-трассе
  - `phase: validate` — на 4G-трассе летят капсулы `CHALLENGE→` и `←RESPONSE`, успех пульсом, бейдж «проверка пройдена · соединение живо»
  - Две трассы (верх Wi-Fi циан пунктиром после обрыва, низ 4G зелёный), центральный бейдж CID SAME, телефоны/сервер по бокам — буквально показывает «смена сети без разрыва»

Документирован в `.claude/skills/animator/catalog.md` (таблица + «Когда использовать»), зарегистрирован в `video/src/lib/types.ts` (enum `quic-migration`), `schema/scenes.schema.json`, `StoryScene.tsx` (schedule, sfx, cam, компонент).

**Почему не форжим остальные ≤3 отдельно:** действия №3–6,10–11 уже закрываются `diagram` (оценка 4–5) и `outro` (5) без нового визуала — они про абстрактный обмен/идентификатор/итог, где схема узлов/пакетов буквальна.
