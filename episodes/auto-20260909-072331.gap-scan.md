## Решения кузницы

Создан один новый visual с шестью фазами, а не шесть разрозненных карточек:

- `answers` буквально связывает один вопрос «Как уснуть?» с карточками
  «Проветри комнату» и «Убери телефон».
- `tokens` оставляет запрос неизменным и достраивает ответ чипами
  `проветри → комнату → и → отдохни`.
- `distribution` превращает распределение в чашу/ряд кандидатных столбцов
  с видимыми разными весами.
- `sample` показывает повторяющиеся записки, отдельный сэмплер и движение
  выбранной записки из чаши; частота записок объясняет вес.
- `branch` показывает переход `выбранный токен → другой контекст → новое
  распределение → два ответа`.
- `temperature` ставит рядом узкий и широкий разброс, показывает API-шкалу
  `0–2` и отсутствие гарантии полной одинаковости.

Композиция сцен одной строкой:

`story/token-sampler[answers] → story/token-sampler[tokens] → story/token-sampler[distribution] → story/token-sampler[sample] → story/token-sampler[branch] → story/token-sampler[temperature] → штатный outro`

Все смысловые группы находятся выше нижних субтитров: заголовок около
`y=238`, основная зона примерно `y=395–1040`, подпись около `y=1090`.
